# 10슬롯 경합과 셰드 여유 — 측정 `[LOCAL]`

측정: `v2c_c3_strawberry30` vs `boatlee`, seed 1000.
`main.py:_plan_market` 를 감싸 **클램프 전** 주문 줄 수를 집계.

## 1. 클램프가 자르는 것은 SELL 이 아니다

주문 구성 순서는 `SELL(가격 내림차순 전량) → BUY_LAND → HIRE → BUY_SEED`
이고 `clamp_market` 은 **꼬리부터** 자른다 (`main.py:408-447, 671`).

```
클램프 전 주문 줄 수 분포:
  {1:5, 2:9, 3:9, 4:3, 5:5, 6:3, 8:2, 9:2, 11:5, 12:10, 13:5, 14:2, 15:2}
10줄 초과 턴: 24
잘려나간 주문: BUY_SEED 32줄, HIRE 26줄   (SELL 은 0줄)
```

**SELL 은 한 번도 잘리지 않는다.** 잘리는 것은 씨앗 32줄과 고용 26줄이다.
→ 우리는 24개 턴에서 **파종과 고용을 못 하고 있다.**
   `orders_truncated` 가 0인 이유는 에이전트가 엔진에 넘기기 전에 스스로 잘랐기 때문이다.
   조용한 손실이 계측기를 통과하고 있었다.

**따라서 브리프의 "SELL 우선순위" 축(C1 vs C2)은 무의미하다. 이미 SELL 우선이다.**
실제 경합은 **BUY_SEED vs HIRE** 다.

## 2. 셰드는 이미 99/100 까지 찬다 — 다만 **현재 손실은 0 이다**

6판 실측 최대 점유:

| 상대 | seed 1000 | seed 1001 |
|---|---|---|
| boatlee | 91 | **99** |
| lynnsakurai | 97 | **99** |
| starter | **99** | 98 |

`main.py:410` 의 주석 "매 턴 비우므로 셰드가 100칸에 닿는 일도 없다" 는 **사실이 아니다** — 99까지 닿는다.

**반사실 실험 — 현재 손실은 0 이다.**
엔진 `shedCapacity` 와 정책 `SHED_CAP` 을 100 → 400 으로 함께 올려 재실행:

| 상대 | seed | cap 100 | cap 400 | 차이 |
|---|---|---|---|---|
| boatlee | 1000 | 42,050 | 42,050 | **0** |
| boatlee | 1001 | 44,684 | 44,684 | **0** |
| starter | 1000 | 50,868 | 50,873 | +5 |
| starter | 1001 | 51,511 | 51,261 | −250 |

→ 100칸 제한이 지금 우리에게 물리는 비용은 **없다.**
   피크 99는 "하루 끝에 전부 입고되고 아직 안 판 순간"의 일시적 값이며,
   h1 에 전량 매도하므로 다음 날 다시 비워진다.

**따라서 이것은 현재 버그가 아니라 지뢰다. 위험한 이유는 여유가 1칸이라는 것이다.**

## 2b. 지뢰가 터지는 방식 — 계측기가 못 잡는다

`guard_shed_capacity` (`main.py:600-621`) 는 셰드가 넘칠 것 같으면
**HARVEST 를 PASS 로 바꾼다.** 버리는 게 아니라 애초에 거두지 않는다.

- `shed_discarded` = 0 (버린 게 없으므로)
- `noop_actions` = 0 (PASS 는 합법 액션이므로)
- 실제 손실: 작물이 밭에 남아 `max_yield_day` 를 지나면
  2스텝마다 yield 가 1씩 깎이다 잡초가 된다 (`_decay_plants`)

**어느 카운터에도 안 잡힌다.** 멜론 오류와 정확히 같은 종류다 —
카운터가 0이라 CLEAN 이라 판정했는데 비용이 카운터가 안 보는 곳으로 옮겨간 것.

## 2c. 여유 1칸을 잡아먹는 두 가지가 예정되어 있다

1. **stage B (매도 분산)** — 일부러 판매를 늦춘다. 피크가 일시적이지 않게 된다.
2. **KAGRI-013 (동물)** — MILK·WOOL·미배치 동물이 **같은 100칸 풀**을 쓴다
   (`kaggriculture.py:171` — `shed = {item: 0 for item in PRODUCTS + list(ANIMALS)}`).

둘 다 확정적으로 여유를 먹는다. 대비 없이 진행하면 손실이 조용히 발생한다.

## 3. 파생 사실 — stage B 가 stage C 를 부분적으로 해결한다

SELL 은 하루 1턴(h1)에 몰려 있고(발행 24턴, hour 분포 `{1:23, 22:1}`),
그 턴에서 SELL 이 앞자리를 다 먹어 BUY_SEED/HIRE 가 잘린다.
매도를 하루 여러 턴으로 분산하면 h1 의 SELL 줄이 줄어 **자동으로 슬롯이 열린다.**

→ B 와 C 는 독립이 아니다. **C 는 반드시 B 승자 위에서 돌려야 한다.**
