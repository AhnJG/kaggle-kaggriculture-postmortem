## 0. 유효성 점검 (먼저)
- 재현: X·D' 각 10판을 자기 파일로 같은 seed·좌석·상대 tape 로 재실행 → 보상 일치해야 함(불일치 1판이라도 있으면 이후 분석 중단·보고).
- 무효: 두 제출의 경기에서 우리 좌석 status ≠ DONE(오류·시간 초과·무효)가 있으면 기록.

## A. 양방향 비교 (주 분석)
- A1: X 의 실제 경기마다 상대 행동 tape 를 만들고 d157 을 같은 seed·좌석으로 실행 → Δ1 = X실제 − d157가상.
- A2: D' 의 실제 경기마다 상대 tape 에 X 를 실행 → Δ2 = X가상 − D'실제.
- 보고: Δ1, Δ2 각각의 평균·경기 bootstrap 95% 구간, 합친 평균 Δ = (ΣΔ1 + ΣΔ2)/(n1+n2).
- 해석: 실제 쪽은 상대가 반응한 closed-loop, 가상 쪽은 open-loop 이다. tape 편향이 가상 봇에 유리하게 작용하면 Δ1 은 X 를 불리하게, Δ2 는 X 를 유리하게 치우친다. 따라서 Δ2 − Δ1 을 **tape 편향의 크기 추정치**로 보고, 합친 Δ 를 주 추정치로 쓴다.
