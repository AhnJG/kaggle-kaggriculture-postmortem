**판정 규칙 (사전등록 대상):**
1. 그룹 g 의 route = M2 평균 점수가 가장 높은 route. 단, 기존 route 보다 +0.05 이상이고 상대 제출 단위 bootstrap 90% 하한 > 0 일 때만 바꾼다. 아니면 기존 route.
2. 기반 선택: 판독 B(비거울판 실전 X 대 D')에서 c26 실전이 d157 보다 낮고 구간이 0 을 넘지 않으면 C_d, 아니면 holdout 전체 점수가 높은 쪽.
3. 제출 조건 (모두 충족): holdout 전체 C − X ≥ 0, 거울판 C − X > 0 / closed-loop (C 대 d157, C 대 55be exact, 각 40 seed × 2좌석)에서 C ≥ X − 0.03 / D3 PASS, 오류 0. 판독에서 거울판 tape 편향(Δ2 − Δ1)이 +0.10 을 넘으면 closed-loop 조건을 C ≥ X 로 올린다.
4. 불통과 → 제출하지 않고 {X, D'} 유지 (판독이 X 되돌리기 R1 을 부르면 그 절차가 우선).
