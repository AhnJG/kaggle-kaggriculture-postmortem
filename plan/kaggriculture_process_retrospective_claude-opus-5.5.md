## 0. 한 페이지 요약

**결과 [사실]**: 25회 제출. 최고 hosted 2425.7(동메달권, 09-23), 최종 1622.2(1,855위, 동메달선 1852.0). 실험 ID 62개(카드가 있는 것은 그중 일부).

**가장 큰 문제 다섯 [평가]**
1. **평가기를 검증하기 전에 평가기로 골랐다.** 로컬 지표가 hosted 방향을 맞히는지 처음 측정한 것은 09-25였고, 결과는 BLOCKED(변별력 ≈0)였다. 그 뒤에도 검증되지 않은 tape 지표로 후보를 골라 제출했다. 같은 계열 안의 미세 변경은 로컬과 hosted가 거의 맞지 않았다.
2. **조율 비용이 실험 비용보다 컸다.** 실험 62개에 문서가 440개 넘게 쌓였다(보고 217, 제안·지시서 165, 프로젝트 문서 62). 실험 하나에 약 7개꼴이다. Claude가 쓴 제안·지시서만 124개다.
3. **"현재 상태" 문서가 셋 다 낡아 있었다.** 10-01 기준 `BOARD.md`는 09-28, `HANDOFF_CURRENT.md`는 09-16, `plan/CURRENT.md`는 09-15에 멈춰 있다. 마지막 git commit은 09-29이고, 커밋되지 않은 파일이 646개다.
4. **AGENTS.md(계약)와 실제 운영이 어긋났다.** RESET(09-10)에서 버린 4봇 승격 게이트(§7.1·§7.1b·§7.3)가 계약에 그대로 남아 있다. "동결"이라 해놓고 이후에도 세 번 고쳤다. 제출 권한(§8)과 소유권(§4)은 마지막 날 실제와 달랐다.
5. **사전등록 판정과 제출 결정이 따로 놀았다.** FAIL·INCONCLUSIVE·검증자 반대를 사람 결정으로 넘어선 제출이 최소 6건이다(yhay81, EXP-007, EXP-016, d157, c26, L4p). 그중 EXP-016은 대회 최고점을 냈다. 판정 규칙은 엄격했지만 *제출 규칙*은 사전에 정해두지 않았다.

**잘 된 것 다섯 [평가]**
- 진실의 순위(규정 → 엔진 → hosted → 로컬 → 커뮤니티)와 증거 꼬리표. 엔진 소스로 확인하는 습관이 흡수량 오류, 진입점 결함, 가격 재평가 같은 실제 버그를 잡았다.
- 한 파일 한 writer, 에이전트별 폴더. 초기에는 사고가 두 번 있었다(EXP-001 실행 중 `main.py` 덮어쓰기, EXP-003 실행 중 다른 작업의 commit이 진행 중 파일을 함께 커밋). 소유 폴더를 나눈 뒤로는 같은 종류의 사고 기록이 없다.
- "모호하면 BLOCKED로 반환"을 계약 준수로 정의한 것. KAGRI-016, EXP-008 B1~B4에서 잘못된 실행을 막았다.
- 독립 검토자 구조. stale artifact, wrapper 자기참조, seat 오류, gate 정의 오류, K10 오등재를 걸러냈다.
- 결과를 보기 전에 기준을 고정하고 사후 완화를 거부한 것(EXP-008 G4, X454).

### 3.3 실험 설계·평가 [사실 → 평가]
- **엄격함은 높았다**: 사전등록, seed·seat·n 고정, Wilson·bootstrap 하한, holdout, 결과 전 기준 고정.
- **대상은 잘못 겨눴다**: 엄격하게 측정한 것은 "로컬 상대 풀에서의 승률"이었고, 그 양이 hosted와 연결된다는 증거는 끝까지 약했다(calibration BLOCKED, sibling 비교 불일치). 측정은 정밀했지만 타당성이 낮았다.
- **hosted 자체를 평가기로 쓰는 설계가 늦었다.** 하루 5회 제출과 두 슬롯이 있었는데, 같은 시간대 A/B(EXP-006 교훈)를 체계적으로 쓰지 않았다. 다만 F-T12(은퇴하면 경기 이력이 소멸) 때문에 이 방식에도 비용이 있다.
- **사전등록 판정과 제출 결정이 섞였다** (§0-5). 판정은 "이 실험이 가설을 지지하는가"이고 제출은 "포트폴리오 기대값"인데, 둘을 한 게이트로 다루다가 마지막에 사람 override가 반복됐다.

### 3.4 기록·소통
- **잘 된 것**: §10.1의 비전공자용 4줄 요약, VERDICT 형식, SHA 기록.
- **부족한 것**: 살아 있는 실험 로그가 없었다. 결정은 대화·보고·프로젝트 문서에 흩어졌다. 그래서 같은 질문("c26이 d157보다 나은가")이 문서 39 → 43 → 45에서 세 번 다른 답으로 나왔다.
